# 📝 To-Do List Application

A to-do list application built with a **Web API** for backend logic and an **ASP.NET MVC** frontend.  
The API can be used independently from the interface by switching to a dedicated branch.

This application was developed as a final project for the **EPAM Systems .NET Fundamentals** course and was inspired by the Microsoft To Do app.

## Features

- Create and manage to-do lists
- Add, edit, and delete tasks
- Assign tasks to specific users
- Organize tasks using tags

## Tech Stack

- **.NET / C#**
- **ASP.NET Core**
- **ASP.NET MVC**
- **Entity Framework**
- **SQLite** (with optional MS SQL Server support)
- **Razor**

## Notes

- The project follows a layered architecture (Web API + MVC frontend)
- The API can be used as a standalone backend
## How to run the project?
- Clone the prject using git clone **repo link**
- Run Web API first: you could do this by navigating to WepApi foloder and running "dotent run" command
- Run Web interface: you could do this by navigating to WepMvc foloder and running "dotent run" command
<p><b>Here we go! It works! Enjoy the application!</b></p>
